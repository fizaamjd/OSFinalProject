# Demo media

The current presentation is a self-contained animated HTML file: [customos-demo.html](customos-demo.html). Download it and open it in a browser, or use the integrated portfolio preview. Fonts and SVG artwork are embedded; playback needs no video file, CDN or build step.

Seven chapters span 68 seconds: desktop, boot/modes, applications, process launch, process inspection, resource budgets and closing. Controls support playback, restart, chapter navigation and seeking; reduced motion pauses autoplay. The interface is an animated reconstruction based on the original GTK project and [LinkedIn demonstration](https://lnkd.in/p/d_2DEMH8). Sample PIDs and resource budgets are illustrative, and UI modes do not imply kernel privileges.

The root README embeds a 1200-square H.264 export at 24 fps rendered directly from this HTML timeline. GitHub does not execute an HTML application inside a README, so the hosted video serves that preview only. Source and export hashes are in checksums.json. The original 2024 demonstration remains linked separately for historical reference.
